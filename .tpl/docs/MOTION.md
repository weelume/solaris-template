# 原站动效清单

- 首屏标题与正文：逐词从 y=20、blur=10px、opacity=.001 进入；每词 50ms，时长 .7s，ease [.12,.23,.17,.98]，标题延迟 .1s、正文 .2s。中文按字符调整错峰。
- 首屏按钮：延迟 .8s、y=20、.4s。
- 首屏房屋：y=100 进入，滚动位移至 150、缩放至 1.1。
- 导航/手机菜单：下移入场，约 .8s 弹簧；菜单项错峰，开关锁定与恢复背景。
- 关于区块与卡片：y=80/100、stiffness=250、damping=80，错峰 0/.2/.4s。
- 计数：0 至 10+、500+、20Years，2s；原站组件质保统计与信任带 25 年文案不一致，保留原站数值。
- 项目 Reel：4 张本地图片，每 4s 切换；图片 .8s 交叉淡变，文字 y=20/.48s 错峰；进度带；悬停暂停/继续、播放键、键盘和触摸切换。原站没有 video 元素。
- 资质轨道以 40px/s 循环滚动，原站 hover 保持 100% 速度；可焦点暂停，离屏停止；普通滚动保持原生。
- 方案卡片：分列错峰上移，hover 图片放大；项目卡片同样错峰。
- 收益项与 FAQ：高度/透明度展开，保持键盘按钮语义。
- 流程：桌面左列 sticky，手机单列；步骤错峰上移。
- 评价：5 条，上一条/下一条，图片和内容过渡。
- 页脚：逐词进入、按钮 hover/press。

减少动态效果关闭循环、滚动变换与入场，保留所有信息及手动控制。各项实际验证状态另见 reports，本文参数清单不表示全部通过。
